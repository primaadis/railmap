   DOKUMENTASI KAI CS RAIL COMMAND CENTER - JAWA & SUMATERA (V3.0 FINAL)
================================================================================

1. LOGIKA NAVIGASI & PENGGUNAAN PETA OLEH CS:
--------------------------------------------------------------------------------
A. Peta Bebas & Utuh (Full Global Support):
   - Pembatasan ketat koordinat (maxBounds) telah dihilangkan. Peta dapat digeser
     dan di-zoom secara mulus tanpa batas kaku.
   - Peta default tetap difokuskan langsung ke gugusan rel Pulau Jawa & Sumatera.

B. Tampilan Kartografi Command Center:
   - "Fokus Rel Bersih": Mode default operasional CS. Latar belakang disederhanakan
     (kanvas abu-abu polos tanpa nama jalan raya) sehingga visualisasi wesel,
     jalur ganda, dan titik stasiun terlihat sangat jelas dan kontras.
   - "Peta Standar": Menampilkan kartografi jalan umum OpenStreetMap jika CS
     perlu memandu akses jalan penumpang ke arah stasiun.
   - "Citra Satelit": Menampilkan foto satelit bumi Esri resolusi tinggi secara legal
     dan tanpa pesan error token API.
   - "Overlay Detail Rel (ORM)": Menampilkan data teknis OpenRailwayMap (wesel,
     jalur langsiran, dan percabangan).

C. Filter Terstruktur Daop 1 s.d. Divre IV:
   - Stasiun di sidebar dikelompokkan dan diurutkan secara tertib dari barat ke
     timur (Daop 1 Jakarta hingga Daop 9 Jember), dilanjutkan dengan Divre I Medan
     hingga Divre IV Tanjungkarang.
   - CS dapat memilih Daop/Divre spesifik melalui menu dropdown, atau mengetik
     langsung nama stasiun (misal: "Poncol", "Tawang", "Lempuyangan", "Medan").

D. Drawer Informasi & Layanan Penumpang:
   - Klik stasiun mana saja untuk membuka drawer sisi kanan.
   - Menyajikan data elevasi ketinggian (mdpl), ulasan CS mengenai karakteristik
     stasiun, checklist fasilitas, dan panduan alur gerbang boarding.
   - Tersedia tautan langsung ke portal tiket Access by KAI (`booking.kai.id`)
     dan kontak resmi WhatsApp KAI 121 (`0811-1211-1121`).


2. CARA MENGGANTI FOTO STASIUN DI REPOSITORY GITHUB:
--------------------------------------------------------------------------------
1. Buka folder: assets/images/stations/
2. Masukkan file foto stasiun berformat .jpg dengan nama sesuai ID stasiun:
   - gmr.jpg  -> Stasiun Gambir
   - pse.jpg  -> Stasiun Pasar Senen
   - smt.jpg  -> Stasiun Semarang Tawang
   - smc.jpg  -> Stasiun Semarang Poncol
   - yk.jpg   -> Stasiun Yogyakarta
   - mdn.jpg  -> Stasiun Medan
   - tnk.jpg  -> Stasiun Tanjung Karang
3. Jika foto lokal belum Anda unggah, sistem secara otomatis mengaktifkan fitur
   fallback darurat sehingga gambar tidak akan rusak atau pecah di layar CS.


3. CARA UPLOAD KE GITHUB & MENGAKTIFKAN GITHUB PAGES:
--------------------------------------------------------------------------------
1. Inisialisasi Git di dalam folder proyek:
   git init
   git add .
   git commit -m "KAI CS Rail Monitor v3.0 Final"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO-ANDA.git
   git push -u origin main

2. Buka repository Anda di browser:
   Masuk ke menu: Settings -> Pages -> Pada bagian 'Branch', pilih 'main' -> Save.
3. Website monitoring Anda akan langsung aktif secara online dan dapat diakses
   kapan saja oleh seluruh petugas Customer Service.
